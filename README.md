# خطوات تشغيل المشروع

* إنشاء الحزم اللازمة لتشغيل المشروع بتنفيذ :
<h6 dir="ltr">

`npm install`

</h6>



* الآن أصبح المشروع جاهز للتشغيل ننفذ الأمر:
<h6 dir="ltr">

`npm run dev`

</h6>

* ننسخ الرابط الذي ظهر ونلصقه بالمتصفح.
